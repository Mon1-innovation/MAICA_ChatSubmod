# 任务意图

## 目标

将 MAICA ChatSubmod 前端修复到后端 v1.3 契约，目标前端版本为 `1.8.0`。修复必须覆盖已确认的 MT、session、MSpire、WebSocket、MVista、设置迁移、昵称和开发覆盖问题，并以自动化测试和发布检查证明结果。

实施从干净的 `1.7.8` 提交重新开始。此前未提交的迁移实现仅保存在 stash 中作为审查证据，不复制为新实现基线；原始 v1.2-to-v1.3 清单与已确认审查问题均需由新代码重新满足。

## 范围

- 修正字段名、字段类型、数量限制、长度限制和事件名。
- 添加发送前校验和响应解析回归测试。
- 迁移既有设置与 `mas_player_additions`，不静默丢失用户内容。
- 退役后端不再支持的旧网络字段、事件和端点。
- 修复 `dev_enable.rpy` 的初始化不变量及 `disable(status)` 签名。

## 非目标

- 不修改后端仓库或上游 API 文档。
- 不引入 Pydantic 到 Ren'Py 包。
- 不重设计界面，不支持 v1.2 网络协议。
- 不进行与本次兼容性问题无关的重构。

## 成功标准

1. 所有出站 MT 和 session 请求符合后端 v1.3 schema。
2. 旧存档从 `1.7.8` 升级到 `1.8.0` 时迁移幂等，玩家自定义信息可恢复。
3. 全部自动化测试通过，运行路径不再发送或监听已退役协议名称。
4. 有 Ren'Py SDK 时 lint 通过；没有 SDK 时记录该项为剩余风险。
