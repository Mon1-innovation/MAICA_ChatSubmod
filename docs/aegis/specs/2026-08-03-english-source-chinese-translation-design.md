# 默认英文与中文翻译互换设计

日期：2026-08-03

## 目标

将 `game/Submods/MAICA_ChatSubmod` 中玩家可见文本的语言所有权反转：英文成为主 `.rpy` 脚本中的默认原文，简体中文成为 `tl` 中由 `config.language == "chinese"` 选择的翻译。迁移后应保持现有剧情、界面行为、存档和后端交互不变。

## 当前结构

- 主 `.rpy` 脚本主要以中文作为玩家可见原文。
- `tl/*.rpy` 主要通过 `translate english` 提供英文译文。
- `api.rpy` 已在未设置语言时将 `config.language` 设为 `"english"`。
- 部分翻译文件同时包含少量 `translate chinese` 样式或文本块，迁移时必须逐项分类，不能全局替换语言名称。

## 迁移规则

采用按现有翻译单元反向迁移的方式：

1. 对带翻译 ID 的对话块，将现有英文译文提升到主脚本中对应语句，并把原中文写入同一翻译 ID 的 `translate chinese` 块。
2. 对 `_()` 字符串，将英文译文提升为主脚本字符串，并将翻译表调整为 `old "英文"`、`new "中文"` 的 `translate chinese strings` 条目。
3. 已有英文译文按原文迁移，不校对、不润色，也不修正拼写或语法。
4. 对没有现成英文译文的玩家可见中文补充英文翻译，再按相同结构保留中文翻译。
5. 保持 label、翻译 ID、变量插值、Ren'Py 文本标签、角色表情、控制语句和调用顺序不变。
6. 现有正确的 `translate chinese` 内容按用途保留；样式覆盖等非反向翻译块不得机械改名。

## 范围

本次处理以下玩家可见内容：

- 角色对话、旁白与菜单选项。
- screen 中的标题、按钮、说明、tooltip 和输入提示。
- 展示给玩家的连接状态、警告和错误信息。
- 其他经 Ren'Py `_()` 或 translate 块本地化的界面文本。

以下内容不在范围内：

- 代码注释、开发说明和 TODO。
- `submod_log`、console 调试输出及仅供开发者查看的异常文本。
- AI prompt、系统消息、原始会话示例和模型生成约束。
- URL、资源路径、标识符及协议字段。
- `item_name_zh`/`item_name_en`、`is_zhcn` 等显式双语业务字段。
- 后端目标生成语言、语言检测和时区选择逻辑。
- 对现有英文译文的质量修订。

## 兼容边界

- 保留 `config.language = "english"` 的默认行为；英文用户无需迁移设置。
- 中文用户仍通过 `config.language == "chinese"` 加载中文翻译。
- 不改变 persistent 数据结构、配置键或存档格式。
- 不改变 MAICA 后端请求中的语言字段，也不把界面语言与模型目标语言重新绑定。
- 不重新生成翻译 ID；已有 ID 是本次迁移的兼容锚点。
- 对翻译条目新增或迁移造成的文件布局变化，仅限对应主脚本和现有 `tl` 文件。

## 校验与错误处理

迁移工具或人工步骤遇到以下情况时必须停止该条目的自动转换并列入人工处理：

- 一个中文原文对应多个不一致的英文译文。
- 翻译 ID 在主脚本中找不到唯一对应语句。
- 中英文的插值变量或文本标签集合不一致。
- 原翻译块包含额外控制语句，不能安全地按文本对交换。

不得通过删除变量、改写标签或重建 label 来强行完成配对。

## 验证

- 静态检查所有迁移条目的翻译 ID 与主脚本引用保持一致。
- 比较中英文插值变量和 Ren'Py 文本标签，确保集合一致。
- 扫描主脚本中剩余的玩家可见中文，并人工确认每个残留项属于明确的非目标或遗漏项。
- 扫描 `tl` 中剩余的 `translate english`，确认每个残留块都有保留理由。
- 运行项目可用的 Ren'Py lint、编译或启动检查，确保脚本语法和翻译表可加载。
- 分别以 `english` 和 `chinese` 抽查聊天入口、设置界面、连接状态、警告、错误提示和主要对话。
- 回归确认模型目标语言、语言检测、时区和持久化设置没有因界面语言迁移发生变化。

## 工作草案

- TaskIntentDraft：交换玩家可见中英文文本的所有权，使英文成为默认原文、中文成为翻译；已有英文原样迁移，缺失英文需补译。
- BaselineReadSetHint：`CLAUDE.md`、`api.rpy`、包含玩家可见文本的主 `.rpy` 文件及其同名 `tl/*.rpy`；实施时还需确认项目可用的 Ren'Py 校验入口。
- ImpactStatementDraft：影响 Ren'Py 文本原文与翻译表，不影响业务逻辑、后端协议、AI prompt、日志、双语业务字段或存档结构；主要风险是翻译 ID、插值变量和文本标签错配。
